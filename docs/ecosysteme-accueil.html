🧭 Comment tout ça marche (en 3 phrases)

  1. omniroute est le moteur : quand une app a besoin d'un modèle IA, elle lui demande, et il choisit le meilleur modèle gratuit du moment.
  2. Les applications (OpenCode, ChatDeck, Solscan OS, Understudy, le pipeline premium) sont les fenêtres que vous ouvrez — elles utilisent toutes ce moteur.
  3. Les filets de sécurité (surveillance 15 min + gardien auto-réparateur + bilan du matin à 8 h) tournent tout seuls et vous préviennent seulement si quelque chose casse.
  4. Voyant rouge ? Cliquez « 🔧 Réparer omniroute » : le pilote rallume Docker puis le moteur (1 à 3 min). Perdu ? Ouvrez le Guide débutant.

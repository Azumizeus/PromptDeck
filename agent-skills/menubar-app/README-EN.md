# ⚡ MEGA PACK — macOS menu-bar app

Global search and one-click activation of the **131 skills + 190 agents** from the menu bar.

🇫🇷 Version française : [`README.md`](README.md)

## Run

```bash
npm install
npm start
```

→ a **⚡** icon appears in the menu bar and in the Dock.

## Shortcuts

| Shortcut | Action |
|---|---|
| **⌥Space** | Open/close the panel (anywhere in macOS — changeable in Settings) |
| **⌘⇧Space** | Settings window |
| **↑ / ↓** | Navigate results |
| **⏎** | Copy the selected item's activation prompt |
| **⌘⏎** | Open the selection in the **default LLM** (Settings) |
| **⇧⏎** | Open in ChatGPT |
| **⌘A** | Select all (composer) |
| **⌘,** | Settings · **Esc** close the panel |

Right-click the ⚡ icon: a cascading menu with ⭐ Favorites, **Skills** and **Agents**
grouped by category — each skill/agent opens an **“Open in”** submenu to launch the
prompt in **12 destinations**: Claude, ChatGPT, Perplexity, Copilot, DeepSeek, Z.ai,
Kimi, Mammouth.ia, the **Freebuff app**, **OpenCode desktop** (`opencode://`),
**OpenCode terminal** — plus a 📋 clipboard option (the prompt is always copied anyway). Then: panel, HTML
Launcher, Settings, Quit. The menu follows the
language chosen in Settings (FR/EN).

## Settings

**Light/dark** theme, **FR/EN** language, **default LLM**, **global shortcut**
(⌥Space default), **launch at startup**, **favorite shortcuts** (⌘1-⌘9) and
**config export/import** (JSON: favorites, recents, preferences) — all
remembered (localStorage + `mgp-prefs.json` for the menu) and synced live with
the panel.

## Packaging (standalone .app)

```bash
npm run build
# → dist/MEGA PACK-darwin-x64/MEGA PACK.app
```

Build is configured for **Intel x64** (your machine). For Apple Silicon:
`--arch=arm64` in `package.json`.

## Troubleshooting

| Problem | Solution |
|---|---|
| `Electron failed to install correctly` | `cd node_modules/electron && node install.js` |
| Truncated zip / missing framework | Download the official zip: `https://github.com/electron/electron/releases/download/v33.4.11/electron-v33.4.11-darwin-x64.zip` → extract into `node_modules/electron/dist` + `printf 'Electron.app/Contents/MacOS/Electron' > node_modules/electron/path.txt` |
| Shortcut opens Spotlight | Change it in Settings (⌥Space recommended — ⌘Space is reserved by macOS) |
| Panel does not open | Run `npm start` again — the app is single-instance, a second launch reveals it |

## Catalog

The panel reads `../interface/catalog-full.js` (generated by `python3 build-interface.py`
from the `agent-skills/` root). After updating the master folder, regenerate the catalog:
the app reloads it at the next start.

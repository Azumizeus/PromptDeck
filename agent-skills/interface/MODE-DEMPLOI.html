❓ FAQ

🔒 Confidentialité — qu'est-ce qui quitte mon Mac ?

Rien, par défaut. Catalogue, prompts ✍️, favoris et config vivent dans ~/Library/Application Support/megapack-menubar/mgp-prefs.json (JSON lisible). L'app n'a aucune télémétrie ni analytique — vérifiable dans le code (main.js). Le seul transfert part quand toi tu ouvres un LLM web : le prompt va vers ce service, comme si tu le collais toi-même.

✍️ Pourquoi l'avertissement « app non signée » à l'ouverture ?

La signature est ad-hoc et non notarisée par Apple (99 $/an + envoi des builds — incompatible avec l'open source gratuit). Un simple chemin de confiance, pas un signal de danger : le code est public. Premier lancement : clic droit → Ouvrir (une fois suffit). Vérification : codesign -dv "MEGA PACK.app" → Signature=adhoc.

🌐 Comment ajouter ma propre destination « Ouvrir dans » ?

Trois points dans menubar-app/main.js : openLLM() (l'URL ?q= ou shell.openPath), I18N (libellés FR/EN) et la liste des destinations du sous-menu. Un système de destinations définies dans les Réglages (sans toucher au code) est en feuille de route.

🧠 Electron, vraiment ? Et la RAM ?

Assumé : ~150 à 300 Mo en résidence. L'équivalent Swift natif serait un second projet pour quelques dizaines de Mo. En échange : développement accessible, dossiers inspectables, réouverture instantanée (panneau caché, pas détruit). Clic droit ⚡ → Quitter libère tout.

⌨️ Pourquoi ⌥Espace et pas ⌘Espace ?

⌘Espace est réservé par Spotlight sur macOS — le raccourci global de l'app serait confisqué. Défaut : ⌥Espace, modifiable dans les Réglages (⌘Espace / ⌃Espace).

🪟 Windows ou Linux ?

Pas pour l'instant : la Tray de la barre de menus, les DMG et lipo sont des briques macOS. Le renderer est portable (Electron) — ouvre une issue sur GitHub si le besoin est réel.

❓ FAQ

🔒 Privacy — what leaves my Mac?

Nothing, by default. Catalog, ✍️ custom prompts, favorites and settings live in ~/Library/Application Support/megapack-menubar/mgp-prefs.json (readable JSON). The app has no telemetry or analytics — verifiable in the code (main.js). The only transfer happens when you open a web LLM: the prompt goes to that service, as if you pasted it yourself.

✍️ Why the "unsigned app" warning?

The signature is ad-hoc, not notarized by Apple ($99/year + uploading every build — incompatible with free open source). Just a trust path, not a danger signal: the code is public. First launch: right-click → Open (once is enough). Verify: codesign -dv "MEGA PACK.app" → Signature=adhoc.

🌐 How to add my own "Open in" destination?

Three spots in menubar-app/main.js: openLLM() (the ?q= URL or shell.openPath), I18N (FR/EN labels) and the submenu destination list. User-defined destinations in Settings (no code needed) are on the roadmap.

🧠 Electron? What about RAM?

Owned: ~150–300 MB resident. A Swift-native equivalent would be a second project to save a few dozen MB. In exchange: accessible development, inspectable files, instant reopen (panel hidden, not destroyed). Right-click ⚡ → Quit frees everything.

⌨️ Why ⌥Space instead of ⌘Space?

⌘Space is reserved by Spotlight on macOS — the app's global shortcut would be taken. Default: ⌥Space, changeable in Settings (⌘Space / ⌃Space).

🪟 Windows or Linux?

Not yet: the menu-bar Tray, DMG and lipo are macOS bricks. The renderer is portable (Electron) — open a GitHub issue if the need is real.

⚡ MEGA PACK Bookmarklet sans extension

Active le panneau 131 skills · 190 agents dans n'importe quelle conversation LLM (Claude, ChatGPT, Gemini, Perplexity, Mistral, Le Chat…) via un simple favori de votre navigateur.

Installation (30 secondes)

  1. Affichez la barre de favoris (Cmd+Shift+B sur Mac / Ctrl+Shift+B ailleurs).
  2. Glissez ce bouton dans la barre de favoris :

    ⚡ MEGA PACK
  3. Ouvrez claude.ai, chatgpt.com… puis cliquez le favori ⚡ MEGA PACK.
  4. Cliquez le bouton ⚡ en bas à droite : cherchez un skill/agent, cliquez → le prompt d'activation est injecté dans la conversation. 🎉

Panneau flottant (aperçu de son fonctionnement)

Le panneau s'ouvre aussi via Ctrl+Shift+K :

• Onglet 🛠 Skills → clic = injecte « Utilise le skill … » dans la zone de texte
• Onglet 👥 Agents → clic = injecte « Agis comme l'agent … »
• Si aucune zone de texte n'est détectée → copie dans le presse-papiers (collez manuellement).

Alternative recommandée : userscript Tampermonkey

Pour un panneau permanent sur tous les sites (pas besoin de cliquer le favori) :

  1. Installez l'extension Tampermonkey.
  2. Créez un nouveau script et collez le contenu de interface/mega-pack-panel-full.user.js (catalogue embarqué — fonctionne seul, sans serveur).
  3. Sauvegardez → le bouton ⚡ apparaît sur tous les sites de chat.

⚠️ Sur macOS, les navigateurs bloquent les scripts file:// chargés depuis une page https (claude.ai, chatgpt.com…) → le favori a besoin du serveur local.
• Lancez le serveur en double-cliquant MEGA-PACK-serveur.command (ou : python3 -m http.server 8788 -d agent-skills/interface)
• Sans serveur du tout : installez mega-pack-panel-full.user.js dans Tampermonkey — c'est l'option la plus fiable.
